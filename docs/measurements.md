# Измерения (этап 0a)

Что измерить — DESIGN.md §10. Условия: голая платформа, 4 мотора, колёса, ESP32 + buck от Pixel 9a, груз 500 г, USB-тестер в разрыв, моторы через `tools/usb_console.py`.

| Параметр | Значение | Условия / примечание | Дата |
|---|---|---|---|
| Ток мотора, холостой ход | | VM = 3,6 В | |
| Ток мотора, упор | | VM = 3,6 В | |
| Напряжение, при котором мотор трогается | | → `min_duty` | |
| Потребление ESP32 от USB | | без Wi-Fi | |
| Ток на шине 5 В, средний | | езда по ровному | |
| Ток на шине 5 В, пик | | старт / упор всех четырёх | |
| Лимит OTG Pixel 9a | | при каком токе порт отключается | |
| Просадка VM на пике | | телеметрия `vm_mv` | |

## Проверка тяги
- [ ] Едет боком по ковру
- [ ] Едет боком по плитке
- [ ] Моторы не греются за 5 мин
